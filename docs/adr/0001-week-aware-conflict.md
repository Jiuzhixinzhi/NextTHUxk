# 0001. 周次感知的时间冲突判定

- 状态：已接受
- 日期：2026-09-17
- 相关：`src/lib/domain/time.ts`（`WeekOcc`/`weeksOf`/`weeksOverlap`/`spansOf`）· `src/lib/domain/conflict.ts`（`spansIntersect`）· `CONTEXT.md`「时间冲突」

## 背景

旧版冲突判定只看「周几 × 大节」，把 1-8 周与 9-16 周的课程判为冲突。教务时间串还含单周、双周、多周段、全周与不可数值化文本，且外校课时间只出现在文字说明（如 `周二、周四 15:00-16:30`）。

## 决策

1. **周次参与判定**：解析出周号集合（单周=奇数集、双周=偶数集、多段并集），仅当集合相交才算重叠；无法数值化（全周/单周/双周/杂文本）取 `unknown` 并**保守判重叠**。
2. **唯一重叠判据**：区间重叠统一走 `spansIntersect`；冲突与课表预览共用 `spansOf` 产出的时段（含 `occ`）。
3. **自定义占用保持全周**：手动占用不按周切换，视为全周占用。
4. **外校课入冲突与课表**：无大节时兜底解析文字说明钟点，使外校课进入冲突检测与课表预览。
5. **预览叠加不按周切换**：课表预览同时显示各周段，不提供「按周过滤」视图。

## 后果

- 用户可见：1-8 周与 9-16 周（及单双周）不再误报；外校课出现在课表中。
- 代价：`unknown` 周次保守判重，可能产生保守误报；解析规则集中在 `domain/time.ts` 并有 `tests/domain.test.ts` 守门。
